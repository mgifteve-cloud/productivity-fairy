# Productivity Fairy

Project Name: Techbaby AI Assistance

Role: Act as a professional full-stack developer, AI engineer, UI/UX designer, and prompt engineering specialist to build a modern, responsive AI-powered productivity website.

Objective: Develop an integrated website that helps small business owners and employees automate workplace tasks, save time, and improve productivity using artificial intelligence.

Context: Businesses spend valuable time writing emails, organising daily tasks, and researching information. Techbaby AI Assistance will simplify these activities through one user-friendly dashboard.

Prompts and Features: Include a Smart Email Generator that creates professional emails in different tones, an AI Task Planner that prioritises tasks and creates schedules, and an AI Research Assistant that summarises information and provides useful insights. Each feature must use structured prompts, accept user input, and generate relevant, editable results.

Requirements: Build a professional, responsive dashboard with sidebar navigation, clear input forms, AI-generated outputs, copy and edit functions, error handling, and secure AI integration. The website must demonstrate problem relevance, high-quality prompt engineering, practical functionality, innovation, responsible AI practices, and professional presentation. Protect user data, secure API keys, and remind users to verify AI-generated information.

Expected Output: Deliver a functional website called Techbaby AI Assistance with all three AI tools integrated into one platform, genuine AI responses when configured, an intuitive user interface, and clear documentation. The completed project must demonstrate practical AI implementation, effective workplace problem-solving, and responsible AI usage.
